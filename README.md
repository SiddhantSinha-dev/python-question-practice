# Python Question Practice

A structured repository containing foundational Python problem-solving exercises.

---

## Repository Structure

- **`integers_and_floats/`**: Mathematical calculations, basic arithmetic logic, and control flow checks (BMI calculator, odd/even check, temperature conversion, simple interest).
- **`lists_tuples_and_sets/`**: Sequence operations, slicing, iterations, and core algorithms (sum, average, min/max calculations).
- **`strings/`**: String formatting, slicing, replacement, and substring extraction techniques.

---

## Progress

This repo is updated daily as part of an ongoing Python practice routine. New topics and scripts are added regularly as I work through fundamentals.

---

## Requirements

- Python 3.8 or higher

---

## How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/SiddhantSinha-dev/python-question-practice
   ```

2. Navigate to the desired topic folder:
   ```bash
   cd python-question-practice/strings
   ```

3. Run any script, example:
   ```bash
   python string_slicing_and_extraction.py
   ```
